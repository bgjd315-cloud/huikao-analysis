# 年度更新流程（以新增 116 年為例）

每年 5 月會考結束、心測中心公布試題後，照下面的順序做。
可以自動化的是「資料整理」；逐題分類與結論文字需要老師核對，不能全自動。

## 1. 準備官方檔案

到心測中心官網「歷屆試題」（https://cap.rcpet.edu.tw/examination.html）下載 116 年各科：

- 試題本 PDF（英語含閱讀、聽力兩本）與聽力音檔
- 試題說明 PDF（含評量向度題數、能力等級示例）
- 選擇題參考答案一覽表
- 數學非選擇題各級分人數百分比統計表

放進 repo 的 `incoming/116/`（這個資料夾不進版本庫）。

## 2. 產生逐年資料初稿（請 Claude 做）

依各科現有的 `data/<科目>/115.json` 格式，產生 `data/<科目>/116.json`：

| 科目 | 資料鍵 | 內容 | 來源 |
| --- | --- | --- | --- |
| 共同 | 題本頁圖 `assets/<科目>/...` | 每頁轉成 webp | 試題本 PDF |
| 共同 | `examData`（英語為 `exR`／`exL`） | 每題文字與在頁面上的位置 | 試題本 PDF 自動擷取 |
| 共同 | `ANS`／`ansData` | 參考答案 | 參考答案一覽表 |
| 共同 | 分類（國文 `Q`、其他 `clsData`） | 每題取材／主題與考點 | **逐題判讀，需核對** |
| 國文 | `SINGLE`、`DIM`、`GROUPS` | 單題數、三向度題數、題組取材 | 試題說明＋判讀 |
| 英語 | `STRUCT`、`SCRIPTS` | 題型結構、聽力稿 | 試題說明 |
| 數學 | `ABIL`、`NSAB`、`GROUPQ`、`NSD`、`NSNOTE` | 能力題數、非選級分統計 | 試題說明、級分統計表 |
| 社會 | `STRUCT`、`GTOPIC` | 題型與能力題數、題組主題 | 試題說明＋判讀 |
| 自然 | `CT`、`GTOPIC` | 能力題數、題組主題 | 試題說明＋判讀 |

## 3. 老師核對

重點看三件事：分類是否合理、答案是否與官方一致、切圖有沒有切到別題。
執行 `python3 build.py`，在本機預覽試題庫逐題檢查。

## 4. 更新跨年度統整與文字

`templates/` 中寫死的內容要一起更新：

- 標題與說明中的「111–115 年」「五年」
- 「五年結論」、重複考點表（`REPEAT`）、等級示例位置（總覽頁 `LV`）
- 總覽頁各科卡片上的數字

## 5. 檢查並發布

```
python3 build.py
python3 tools/verify.py      # 需要 playwright；全部顯示 OK 才發布
git add . && git commit -m "新增 116 年" && git push
```

推送後約 1–2 分鐘，網站自動更新。
