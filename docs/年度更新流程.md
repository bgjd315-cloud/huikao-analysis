# 年度更新流程（以新增 116 年為例）

每年 5 月會考結束、心測中心公布試題後，照下面的順序做。
可以自動化的是「資料整理」；逐題分類與結論文字需要老師核對，不能全自動。

## 1. 準備官方檔案

到心測中心官網「歷屆試題」（https://cap.rcpet.edu.tw/examination.html）下載 116 年各科：

- 試題本 PDF（英語含閱讀、聽力兩本）與聽力音檔
- 試題說明 PDF（含評量向度題數、能力等級示例）
- 選擇題參考答案一覽表
- 數學非選擇題各級分人數百分比統計表

放進 repo 的 `incoming/116/`（這個資料夾不進版本庫）。

## 2. 產生逐年資料初稿（請 Claude 做）

依各科現有的 `data/<科目>/115.json` 格式，產生 `data/<科目>/116.json`：

| 科目 | 資料鍵 | 內容 | 來源 |
| --- | --- | --- | --- |
| 共同 | 題本頁圖 `assets/<科目>/...` | 每頁轉成 webp | 試題本 PDF |
| 共同 | `examData`（英語為 `exR`／`exL`） | 每題文字與在頁面上的位置 | 試題本 PDF 自動擷取 |
| 共同 | `ANS`／`ansData` | 參考答案 | 參考答案一覽表 |
| 共同 | 分類（國文 `Q`、其他 `clsData`） | 每題取材／主題與考點 | **逐題判讀，需核對** |
| 國文 | `SINGLE`、`DIM`、`GROUPS` | 單題數、三向度題數、題組取材 | 試題說明＋判讀 |
| 英語 | `STRUCT`、`SCRIPTS` | 題型結構、聽力稿 | 試題說明 |
| 數學 | `ABIL`、`NSAB`、`GROUPQ`、`NSD`、`NSNOTE` | 能力題數、非選級分統計 | 試題說明、級分統計表 |
| 社會 | `STRUCT`、`GTOPIC` | 題型與能力題數、題組主題 | 試題說明＋判讀 |
| 自然 | `CT`、`GTOPIC` | 能力題數、題組主題 | 試題說明＋判讀 |

## 3. 老師核對

重點看三件事：分類是否合理、答案是否與官方一致、切圖有沒有切到別題。
執行 `python3 build.py`，在本機預覽試題庫逐題檢查。

## 4. 更新跨年度統整與文字

`templates/` 中寫死的內容要一起更新：

- 標題與說明中的「111–115 年」「五年」
- 「五年結論」、重複考點表（`REPEAT`）、等級示例位置（總覽頁 `LV`）
- 總覽頁各科卡片上的數字

## 5. 檢查並發布

```
python3 build.py
python3 tools/verify.py      # 需要 playwright；全部顯示 OK 才發布
git add . && git commit -m "新增 116 年" && git push
```

推送後約 1–2 分鐘，網站自動更新。

# 學測國文年度更新（以新增 116 年為例）

學測在 1 月考、2 月下旬公布試題，比會考早。

1. **下載官方檔案**：到大考中心「學科能力測驗 歷年試題」（https://www.ceec.edu.tw/xmfile?xsmsid=0J052424829869345634）下載 116 年國綜的試卷 PDF、選擇題答案、非選擇題參考答案與評分原則，存成 `incoming/xuece/116-paper.pdf`、`116-ans.pdf`、`116-nonchoice.pdf`。
2. **切圖與擷取**：`python tools/xuece/extract.py 116`，會產生 `assets/xuece/pages/116-*.webp` 與擷取結果，並印出題數、題組、單選／多選／混合題範圍。
3. **逐題分類（請 Claude 做，老師核對）**：在 `tools/xuece/classify.py` 的 `Q`、`GROUPS` 加上 116 年。語文知識題的說明要用固定詞頭（字音、字形、成語、詞義、語法、修辭、應用文、文學常識、文化常識），非選題的說明以「非選：」開頭。
   國寫：另下載國寫試卷存成 `116-w-paper.pdf`，執行 `python tools/xuece/extract_writing.py 116`，並在 `classify.py` 的 `WRITE` 補上兩大題的材料類型與主題。
4. **合併與檢查**：`python tools/xuece/merge.py 116`（國寫每大題配分合計不是 25 分也會停下來）。題數、題組範圍、非選題號任何一項對不上都會停下來並說明原因。
5. **更新文字**：`templates/xuece.html` 中寫死的「107–115 年」「九年」、九年結論與教學建議；總覽頁學測卡片的年度。
6. **檢查並發布**：同上方第 5 步。

## 學測英文

1. 下載英文考科試卷、選擇題答案、非選擇題參考答案與評分原則，存成 `incoming/xuece/116-e-paper.pdf`、`116-e-ans.pdf`、`116-e-rubric.pdf`。
2. `python tools/xuece/extract_en.py 116`：切圖並印出各題型範圍、題組數、翻譯句數。
3. 在 `tools/xuece/classify_en.py` 的 `TOPIC`（依題組順序的短文主題）與 `ESSAY`（作文題型、主題、段落要求）補上 116 年。
4. `python tools/xuece/merge_en.py 116`：自動產生答案字與閱讀題型，並解析混合題參考答案；題組數對不上、抓不到答案字或參考答案都會停下來。
5. 更新 `templates/xuece-en.html` 的「107–115 年」「九年」與結論文字，再依上方第 5 步檢查並發布。

## 學測數學

1. 下載數學A、數學B 的試卷與選擇（填）題答案，存成 `incoming/xuece/116-ma-paper.pdf`、`116-ma-ans.pdf`、`116-mb-paper.pdf`、`116-mb-ans.pdf`（評分原則可另存 `-rubric.pdf` 備查）。
2. `python tools/xuece/extract_math.py 116-ma 116-mb`：切圖、題型範圍與答案；試卷題號與答案表對不上會停下來。
3. 在 `tools/xuece/classify_math.py` 補上 `"116-ma"`、`"116-mb"` 各 20 題的單元與考點。
4. `python tools/xuece/merge_math.py 116`：檢查每份試卷配分合計 100 分、混合題 15 分。
5. 更新 `templates/xuece-math.html` 的年度與結論文字，再依上方第 5 步檢查並發布。

數學甲（分科測驗，7 月考）：從大考中心「分科測驗（110 前指考）」歷年試題頁下載，存成 `116-mj-paper.pdf`、`116-mj-ans.pdf`，執行 `python tools/xuece/extract_math.py 116-mj`，在 `classify_math.py` 補上 `"116-mj"`（可用 G 微積分、Z 複數），再執行 `merge_math.py 116`。

數學乙（分科測驗）：同上，檔名與分類鍵改用 `mi`（如 `116-mi-paper.pdf`、`"116-mi"`）。

## 學測社會

1. 下載社會考科試卷、選擇題答案、非選擇題評分原則，存成 `incoming/xuece/116-s-paper.pdf`、`116-s-ans.pdf`、`116-s-rubric.pdf`。
2. `python tools/xuece/extract_social.py 116`：切圖、題組、混合題起點；題號與答案表不符會停下來。
3. 在 `tools/xuece/classify_social.py` 補上 116 年的 `Q`（每題科別領域代號與考點，非選題考點以「非選：」開頭），並從評分原則總說明抄入 `NS_PTS`（各非選題配分；總說明也列出各題科別，可用來核對）。
4. `python tools/xuece/merge_social.py 116`：檢查非選題號、配分合計 144 分。
5. 更新 `templates/xuece-soc.html` 的年度與結論文字，再依上方第 5 步檢查並發布。

## 學測自然

1. 下載自然考科試卷、選擇題答案、非選擇題評分原則，存成 `incoming/xuece/116-n-paper.pdf`、`116-n-ans.pdf`、`116-n-rubric.pdf`。
2. `python tools/xuece/extract_social.py --subj n 116`：切圖、題組、第貳部分起點（與社會共用程式）；題號與答案表不符會停下來。
3. 在 `tools/xuece/classify_science.py` 補上 116 年的 `Q`（每題科別代號 P／C／B／E 與考點，非選題考點以「非選：」開頭），並從評分原則總說明抄入 `NS_PTS`（總說明也列出各題科別，可用來核對）。
4. `python tools/xuece/merge_science.py 116`：檢查非選題號、第壹部分 72 分與第貳部分 56 分。
5. 更新 `templates/xuece-sci.html` 的年度與結論文字，再依上方第 5 步檢查並發布。

在 Windows 上指令用 `python`（不是 `python3`）；若中文訊息亂碼，先設定 `PYTHONIOENCODING=utf-8`。
